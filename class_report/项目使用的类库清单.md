# 项目使用的类库清单

## 一、GUI类库

### 1. Qt Core模块
Qt的核心功能模块，提供基础类和功能：
- **QObject** - 所有Qt对象的基类，支持信号槽机制
- **QString** - 字符串处理类
- **QTimer** - 定时器类，用于动画和延迟执行
- **QFile** - 文件操作类
- **QTextStream** - 文本流处理类
- **QMap** - 键值对映射容器
- **QList** - 列表容器
- **QPointF** - 浮点坐标点
- **QVariant** - 通用数据类型包装器
- **QDateTime** - 日期时间处理

### 2. Qt GUI模块
Qt的图形用户界面基础模块：
- **QApplication** - 应用程序主类
- **QColor** - 颜色类
- **QFont** - 字体类
- **QPen** - 画笔类
- **QBrush** - 画刷类
- **QPainter** - 绘图类
- **QPainterPath** - 绘图路径类
- **QPainterPathStroker** - 路径描边类
- **QStyleOptionGraphicsItem** - 图形项样式选项
- **QWidget** - 所有窗口部件的基类
- **QLocale** - 本地化支持

### 3. Qt Widgets模块
Qt的窗口部件模块，提供丰富的UI控件：
- **QMainWindow** - 主窗口类
- **QDialog** - 对话框基类
- **QPushButton** - 按钮控件
- **QLabel** - 标签控件
- **QLineEdit** - 单行文本输入框
- **QTextEdit** - 多行文本编辑器
- **QComboBox** - 下拉组合框
- **QSpinBox** - 数字输入框
- **QCheckBox** - 复选框
- **QSlider** - 滑块控件
- **QProgressBar** - 进度条
- **QTableWidget** - 表格控件
- **QGroupBox** - 分组框
- **QMenuBar** - 菜单栏
- **QStatusBar** - 状态栏
- **QTabWidget** - 标签页控件
- **QStackedWidget** - 堆叠窗口部件
- **QSplitter** - 分割器
- **QScrollArea** - 滚动区域
- **QHeaderView** - 表头视图
- **QMessageBox** - 消息对话框
- **QFileDialog** - 文件对话框

### 4. Qt Graphics View Framework（图形视图框架）
用于2D图形可视化的高级框架：
- **QGraphicsView** - 图形视图，用于显示图形场景
- **QGraphicsScene** - 图形场景，管理图形项
- **QGraphicsItem** - 图形项基类
- **QGraphicsEffect** - 图形效果基类
- **QGraphicsDropShadowEffect** - 阴影效果
- **QPropertyAnimation** - 属性动画类

### 5. Qt UI Forms
Qt Designer设计的UI表单：
- **mainwindow.ui** - 主窗口UI设计文件
- 通过Qt的UI编译器（uic）生成对应的C++代码

### 6. Qt Translations（国际化支持）
- **QTranslator** - 翻译器类
- **QLocale** - 本地化类
- **StructureVisual_zh_CN.ts** - 中文翻译文件
- 支持多语言界面切换

### 7. Qt JSON模块
JSON数据处理支持：
- **QJsonDocument** - JSON文档类
- **QJsonObject** - JSON对象类
- **QJsonArray** - JSON数组类
- **QJsonParseError** - JSON解析错误类
- **QStringConverter** - 字符串转换器

### 8. Qt Math模块
- **QtMath** - Qt数学函数库（包含数学计算函数）

## 二、其他类库

### 1. C++标准库（STL - Standard Template Library）

#### 1.1 容器类（Containers）
- **std::vector** - 动态数组容器
- **std::map** - 有序键值对映射
- **std::set** - 有序集合
- **std::queue** - 队列容器
- **std::stack** - 栈容器
- **std::list** - 双向链表（可能使用）

#### 1.2 算法库（Algorithms）
- **std::algorithm** - 标准算法库
  - 包含排序、查找、变换等常用算法函数

#### 1.3 随机数库（Random）
- **std::random** - 随机数生成库
  - 用于生成随机数，如图的随机布局、排序数据的随机生成等

#### 1.4 内存管理（Memory）
- **std::memory** - 智能指针库
  - **std::unique_ptr** - 独占所有权智能指针
  - **std::shared_ptr** - 共享所有权智能指针
  - **std::weak_ptr** - 弱引用智能指针

#### 1.5 异常处理（Exception Handling）
- **std::stdexcept** - 标准异常类库
  - 提供各种标准异常类型

#### 1.6 字符串处理（String Handling）
- **cstring** - C风格字符串处理
  - strlen, strcpy, memcpy等函数
- **cstddef** - 标准定义
  - size_t等类型定义

#### 1.7 工具库（Utilities）
- **std::utility** - 工具库
  - std::move等移动语义支持
- **climits** - C语言整数限制
  - INT_MAX等常量定义

#### 1.8 数学库（Mathematics）
- **cmath** - C数学库（通过QtMath间接使用）
  - 数学计算函数

## 三、项目配置说明

### Qt版本要求
- **Qt 6.10.1** 或更高版本（根据.pro文件中的配置）
- 使用 **MinGW 64-bit** 编译器

### C++标准
- **C++17** 标准（在.pro文件中配置：`CONFIG += c++17`）

### 项目模块配置
```qmake
QT += core gui
greaterThan(QT_MAJOR_VERSION, 4): QT += widgets
```

## 五、总结

本项目主要依赖**Qt框架**进行GUI开发，使用**C++标准库（STL）**进行底层数据结构和算法实现。项目充分利用了Qt的图形视图框架实现数据结构的可视化，同时使用STL提供的高效容器和算法来支持核心功能。

**主要特点**：
1. GUI完全基于Qt框架，提供跨平台支持
2. 使用Qt Graphics View Framework实现高性能的2D图形可视化
3. 使用C++标准库实现核心数据结构和算法，保证代码的可移植性
4. 支持国际化，提供中文界面
5. 使用JSON格式进行数据存储和交换
