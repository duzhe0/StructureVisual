## 🔄 如何恢复使用

如果需要恢复使用unused文件夹中的文件：

1. **恢复模板类**：
   ```bash
   # 将文件移回项目根目录
   Move-Item unused/Graph.h .
   Move-Item unused/IGraph.h .
   # ... 其他文件
   
   # 在StructureVisual.pro中添加文件引用
   ```

2. **编译测试文件**：
   ```bash
   # 测试文件可以单独编译
   g++ test_MyVectorQString.cpp MyVectorQString.cpp -o test
   ```
